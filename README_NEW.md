# 🏝️ 台灣注音大冒險

> 一個結合台灣文化與注音學習的互動式教育遊戲

## ✨ 特色

### 🎯 雙模式設計
- **冒險模式**：全新的台灣環島冒險體驗
- **經典模式**：保留原版簡潔遊戲玩法
- 一鍵切換，進度分開儲存

### 🗺️ 環島學習之旅
- **10 個章節**：從台北到離島，探索台灣各地
- **100 個關卡**：漸進式難度設計
- **星級系統**：挑戰三星完美通關
- **Boss 關卡**：每章節特殊挑戰

### 🎨 台灣文化主題
- **台灣配色**：藍天、珍奶、芒果、夜市紅
- **地標景點**：台北101、日月潭、墾丁等
- **明信片風格**：獨特的視覺設計
- **本土字體**：使用教育部標準楷書

### 🎮 遊戲化學習
- **即時回饋**：答題音效與動畫
- **Combo 連擊**：連續答對獲得獎勵
- **進度視覺化**：地圖顯示學習軌跡
- **成就系統**：收集台灣明信片與小吃

## 📱 使用說明

### 第一次使用
1. 輸入你的名字
2. 選擇「開始新冒險」
3. 在地圖上選擇關卡
4. 開始答題學習！

### 版本切換
- 點擊主選單右上角 ⚙️ 圖示
- 選擇「切換到經典模式」
- 體驗原版簡潔玩法

### 功能導覽

#### 主選單
- 🚀 **開始新冒險**：開啟地圖選關
- ▶️ **繼續遊戲**：回到上次進度
- 📚 **學習筆記**：查看錯題與統計（開發中）
- 🏆 **成就收藏**：明信片與成就（開發中）
- 👥 **排行榜**：與其他玩家比較

#### 地圖系統
- 查看10個章節
- 點擊章節查看關卡
- 選擇已解鎖的關卡挑戰
- 查看完成進度與星數

#### 答題遊戲
- 閱讀中文字與英文翻譯
- 選擇正確的注音拼音
- 連續答對獲得 Combo
- 完成關卡獲得星級評分

## 🎵 音效系統

使用 Web Audio API 生成的音效：

- ✅ **答對**：上升音階，愉快的音效
- ❌ **答錯**：下降音階，錯誤提示
- 🔥 **Combo**：高頻特殊音效
- ⭐ **完成**：升級音階

可以在設定中調整音量或關閉音效。

## 📊 進度儲存

遊戲進度自動儲存在瀏覽器 LocalStorage：

- 玩家名字
- 完成的關卡
- 每關的星數
- 總星數與等級
- Combo 最高紀錄

## 🛠️ 技術架構

### 前端框架
- **Svelte 5**：現代化的反應式框架
- **Vite 6**：快速的建置工具
- **Vanilla CSS**：自訂樣式系統

### 資料庫
- **Supabase**：排行榜與雲端同步
- **LocalStorage**：本地進度儲存

### 特色技術
- **Web Audio API**：音效生成
- **Speech Synthesis**：注音發音
- **CSS Animations**：流暢動畫效果
