輪 1 抓到並修正的史實錯誤（5 題）

這些正是 spec §1.2 警告的「冷知識易誤傳」陷阱——若靠記憶不查證會教錯小孩。

FIXgen-quyuan-05線上查證

史實錯誤。題目與答案宣稱汨羅江是『湘江的支流』，但維基百科『汨羅江』條明載『汨羅江是洞庭湖濱湖區主要河流之一』，源於江西修水縣，於江口直接匯入洞庭湖，並非湘江支流。汨羅江與湘江同屬洞庭湖水系/長江流域但互相獨立，汨羅江是洞庭湖支流而非湘江支流。原四個選項（湘江/長江本流/珠江/黃河）無一正確（亦非長江本流直接支流，須經洞庭湖）。原題前提結構性錯誤。改寫為可查證且正確的『汨羅江最後注入哪個大湖』，答案洞庭湖。

FIXgen-boat-29線上查證

內容（鄉民划船搶救屈原→演變為年年競渡）為流傳廣泛的通俗起源說，方向可用；但所引來源《續齊諧記》實為記載『角黍/粽子』起源（屈原託夢、五彩絲楝葉防蛟龍）的文獻，並非競渡搶救說的出處。競渡『救屈原』說多見於《荊楚歲時記》。僅修正來源引用以免誤導，題幹與選項不動。

FIXgen-poem-20線上查證

答案（宋玉=美男子代名詞、屈原弟子、貌比潘安才比宋玉）查證正確：宋玉相傳為屈原學生，後世以『美如宋玉、貌若潘安』形容男子俊美。但 fun 有兩處錯誤：(1)引文誤植為『增之一分太長…增一分則太肥』，《登徒子好色賦》原文為『增之一分則太長，減之一分則太短』，無『太肥』；(2)『東家之子』描寫的是宋玉鄰家的美女（女性容貌），非宋玉本人之美，fun 把它當成形容宋玉俊美的例證屬張冠李戴。修正 fun 改用真正與宋玉俊美相關的『宋玉東牆』典故，並正確標明東家之子是美女不是宋玉自己。

FIXgen-king-17線上查證

正解『王爺（代天巡狩/瘟王司瘟疫）』本身正確（內政部宗教知識、台灣光華雜誌：瘟神信仰演化為代天巡狩王爺）。但題目premise把『送王船/送瘟』綁在端午有誤：台灣最著名的送王船（東港迎王）為三年一科之王醮，並非端午節活動，會誤導小孩以為送王船在端午舉行。改寫為端午確實存在、且確實由王爺指示主事的鹿港海線『送肉粽（送煞）』驅煞儀式，正解仍為王爺，史實與時序皆站得住。

FIXgen-king-20線上查證

正解『須在端午正午取水才算午時水』本身正確，但題目舉例『鹿港龍山寺辦取午時水活動』查無實據：鹿港龍山寺端午辦的是迎龍王尊神/龍舟開光點睛（彰化縣府、taiwangods 資料），非取午時水。台灣最具代表性的午時水聖地是大甲鐵砧山劍井（鄭成功插劍湧泉傳說，每年端午發放紀念瓶、民眾爭領，大紀元/維基『劍井』）。改用正確地點，正解不變。
