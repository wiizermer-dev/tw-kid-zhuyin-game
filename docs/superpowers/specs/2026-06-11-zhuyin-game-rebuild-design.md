# 注音遊戲砍掉重做 — 設計文件

日期：2026-06-11
狀態：autonomous goal session（使用者以 /goal 給定完整需求並授權自主執行，設計決策依 goal 內容自主拍板）

## 一、遊戲精神（不變）

用有趣、好玩、簡單的操作練習生難僻字與注音。簡單有力：看字 → 選注音 → 立即回饋 → 想分享。

## 二、品牌與調性

- 遊戲名：**「ㄅㄆㄇ你會唸嗎？」**（短稱「會唸嗎？」）
- 病毒鉤子即品牌：每張分享卡、每個挑戰連結都以「這題你會唸嗎？」開場。
- 視覺調性：活潑可愛 + 注音文字意象。教育部標準楷書（edukai，已在 public/fonts）呈現漢字與注音直書，搭配糖果色圓角卡片、果凍彈跳動畫、注音符號當裝飾圖形（大型 ㄅㄆㄇ 漂浮背景、聲調符號做 UI 點綴）。
- 計分氛圍：連擊火焰、彈出 +分數、答錯也要可愛（不挫折）。

## 三、題庫結構大改版（核心解耦）

### 問題
舊題庫：14 個檔案、互異 schema（idiom/classical/poetry/proverb/similarSound/multiPron 各一種格式）、生成器逐型別寫死 → 新玩法 = 改全部。大量題目無鑑別度（正解 vs 純聲調缺漏）或答案錯誤。

### 新 schema（單一、扁平、玩法無關）
`src/data/bank/*.js` 每筆：

```js
{
  id: 'tricky-001',
  text: '莘莘學子',        // 完整顯示文字（詞/成語/句）
  target: '莘',            // 考的字
  zhuyin: 'ㄕㄣ',          // 正解（單字注音，含聲調）
  distractors: ['ㄒㄧㄣ', 'ㄕㄥ', 'ㄒㄧㄥ'],  // 2–3 個高混淆錯項
  meaning: '形容眾多的學生',
  fun: '新聞主播都唸錯過，唸「辛」直接被國文老師抓走',  // 趣味哏註解（回饋時顯示）
  tags: ['易讀錯', '新聞常錯'],
  difficulty: 2,           // 1–5
  era: 'classic' | 'modern' | 'meme'
}
```

原則：
- **錯項必須是真實混淆音**（常見誤讀、形近字音、方言影響），禁止「正解去聲調」湊數。
- 每題自帶完整選項與註解 → 任何玩法直接取用，不需逐型別生成器。
- 題庫檔案按主題分檔但 schema 一致：`tricky.js`（易讀錯）、`polyphone.js`（破音字）、`rare.js`（生僻字）、`idiom.js`（成語難讀）、`modern.js`（年輕世代／時事／諧音梗）。
- `scripts/validate-bank.mjs`：檢查 schema 完整、注音字元合法、distractor 不等於正解、id 唯一。

### 內容策略
舊題全部丟棄（不知道在問什麼/答案錯的不再修），重寫精選 200+ 題：
- 易讀錯字：呱呱墜地、莘莘學子、暴殄天物、心寬體胖、一暴十寒…
- 破音字：語境題（「銀行」vs「行走」），只收真正會錯的。
- 生僻字：饕餮、魑魅魍魎、齟齬、耄耋、彳亍…
- 現代／梗：尷尬(ㄍㄢ ㄍㄚˋ)、髮香、網路用語正字（「老饕」）、諧音梗題（答對才懂的梗）、時事常錯字。

## 四、玩法（一個引擎、四種模式）

共用 `QuizSession`（題目佇列、計分、連擊、計時、回饋），模式只是設定 + 少量專屬 UI：

1. **每日挑戰**（病毒核心）：日期種子，全球同 10 題。結果可複製 emoji 方格（Wordle 式）+ 連續天數 streak。
2. **限時衝刺**：60 秒盡量答，連擊加成，分數越高稱號越狂。原「困難模式」的升級版。
3. **闖關冒險**（原玩法升級）:精簡為一條進度路線，每 5 關一個 BOSS（HP 條、答對扣血、答錯自己掉心），三星評價。不再 40 關 8 章節的龐大地圖。
4. **好友對戰（開房）**：產生房間連結（內含種子）→ 朋友開同一組題 → 分數直接對決。**無後端也能玩**：連結帶上開房者分數與名字，對手打完直接看勝負；Supabase 有設定時房間排行榜即時同步。

流程統一：選模式 →（玩）→ 即時計分 →（賽果）成績卡 + 稱號 + 分享 →（排行榜）。

## 五、分享與病毒機制

- **稱號系統**：依表現給好笑、想曬的稱號（「注音之神」「國文老師的驕傲」「ㄅㄆㄇ難民」「菜，就多練」），稱號印在分享卡上。
- **分享卡**：Canvas 產生 9:16 限動尺寸卡片（分數、稱號、最難一題「這題你會唸嗎？」），`navigator.share` 分享檔案到 IG/LINE，桌機 fallback 下載 + 複製文字。
- **挑戰連結**：`?c=<base64url(seed|mode|score|name)>`，朋友點開即進對戰，一鍵完成「被挑戰」迴圈。
- **每日 emoji 方格**：低門檻文字分享。
- **答錯也想分享**：錯題回饋顯示 fun 哏 + 全球答錯率（Supabase 可用時），「87% 的人都唸錯」本身就是分享素材。
